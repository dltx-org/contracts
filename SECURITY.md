# Security

If you find a vulnerability in these contracts, report it privately so it can be fixed before anyone
can exploit it. Please do not open a public issue.

## How to report

- **GitHub:** this repository's Security tab → *Report a vulnerability* (a private advisory only the
  DLTX team can read).
- **Email:** security@dltx.org

Include the contract and function affected, the steps to reproduce it (a Foundry test is ideal), and
the impact you see.

## What we commit to

- A first reply within 72 hours.
- Keeping you informed until it is fixed, and crediting you when it is disclosed, if you wish.
- No legal action against research done in good faith: on a local network or a fork, without
  touching other people's funds, and reported to us before anyone else.

There is no bug bounty programme yet.
